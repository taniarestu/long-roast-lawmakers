## The entry

> They can draft a 400-page law on artificial intelligence before breakfast, but ask them to turn a Word document into a PDF and suddenly the hearing needs a recess, a consultant, and a teenager.

One sentence, 193 characters: it sets up the lawmakers' authority, then
undercuts it with the file they cannot convert, the punch landing on the
teenager called in to save the hearing.
